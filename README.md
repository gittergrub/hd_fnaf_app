# Five Night's at Freddys HTML (Webview)
 Containing every possible FNAF HTML game as webview apps. Currently incomplete and using Electron, will migrate to Tauri.
 This is mainly intended to make it possible for unsupported platforms to play the Clickteam FNAF games offline easier.<br>
 Games available: 1, 2, 3, 4, World, Sister Location, Pizzeria Simulator, and Ultimate Custom Night!<br>
 Press ```-=``` for fullscreen
