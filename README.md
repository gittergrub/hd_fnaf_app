# Five Night's at Freddys HTML (Electron JS)
 Containing every possible FNAF HTML game in ElectronJS apps.
 This is mainly intended to make it possible for unsupported platforms to play the Clickteam FNAF games offline.<br>
 Games available: 1, 2, 3, 4, World, Sister Location, Pizzeria Simulator, and Ultimate Custom Night!<br>
 Press ```-=``` for fullscreen
